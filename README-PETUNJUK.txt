RUSTBOT TRADE AI - PWA LAUNCHER GRATIS
======================================
PENTING: Ini PWA launcher untuk membuka dashboard Google Apps Script yang sudah berfungsi, BUKAN migrasi penuh dashboard ke GitHub Pages.

1. Di repositori GitHub, hapus file kosong bernama 'index' (tanpa .html) jika perlu.
2. Upload SEMUA file dari ZIP ini ke ROOT repositori (jangan upload ZIP sebagai satu file).
3. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
4. Buka alamat GitHub Pages proyek melalui Chrome Android.
5. Masukkan URL Google Apps Script deployment /exec milik Anda, lalu tekan Simpan.
6. Tekan Buka Dashboard Trading untuk membuka aplikasi asli.
7. Dari Chrome, pilih menu > Install app / Tambahkan ke layar utama.

CATATAN PENTING:
- Dashboard asli terbuka di tab browser baru, karena google.script.run hanya bekerja di halaman yang disajikan Google Apps Script. PWA ini belum menjalankan dashboard di dalam layar standalone.
- Agar seluruh dashboard benar-benar terintegrasi ke PWA, perlu migrasi backend API dan penanganan autentikasi/CORS secara terpisah.
- Jangan mengunggah HTML lama yang mengandung Twelve Data API key ke repositori publik.
- Hosting GitHub Pages gratis, Google Apps Script dan data market tunduk kuota masing-masing.
- Launcher dapat tampil offline, tetapi harga/grafik live memerlukan internet.
